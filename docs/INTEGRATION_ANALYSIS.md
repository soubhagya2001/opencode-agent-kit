- Netlify & Daytona MCPs **not** integrated (require API keys; low value for this kit's defaults)

## 5. Potential configuration conflicts & resolutions

| Risk                     | Resolution                                                                                                                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent name collisions    | Verified: none of the 14 new agent keys exist in `opencode.json`                                                                                                                        |
| Command name collisions  | Verified: none of the 8 new command files collide with the 69 existing                                                                                                                  |
| Skill name collisions    | 6 skipped (§4.2); remaining 88 unique                                                                                                                                                   |
| `.env` access rules      | Skeletorflet used `edit: ask / bash: ask` globally — **rejected**; defuj's `edit: allow` + deny-list permissions preserved untouched                                                    |
| Model providers          | None added or changed; no `model` fields introduced                                                                                                                                     |
| Instructions array bloat | New skills are NOT added to the always-loaded `instructions` list; they load on demand via the skill tool                                                                               |
| Template/installer drift | `scripts/generate-template.sh` updated to include `agents/`, `tools/`, `workflows/`, `scripts/` dirs; `bin/commands/init.mjs` copies all of `.opencode/` recursively (no change needed) |
| Custom tools runtime     | Skeletorflet tools used `Bun.$`; rewritten with `node:child_process` for runtime portability                                                                                            |
| Encoding                 | Donor files are valid UTF-8 (console-only mojibake); copied verbatim                                                                                                                    |
